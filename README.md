**digit-recognizer**
a little ML project that recognizes handwritten digits

trained a CNN on the Kaggle Digit Recognizer dataset and made a website where you can draw a digit and see what it predicts

link: _https://digit-recognizer-5ft3.onrender.com/_

_-CNN with TensorFlow / Keras
-~98.88% validation accuracy
-built with Python, Flask, HTML, CSS & JavaScript_

still improving things, but this was fun :)
